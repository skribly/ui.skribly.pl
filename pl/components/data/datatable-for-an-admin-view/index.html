DataTable for an admin view

Pełna siatka panelu administracyjnego na 2000 wpisach: wyszukiwanie, filtry fasetowe z chipami, sortowanie po kilku kolumnach (Shift z kliknięciem dodaje kolejny klucz), kolumny do ukrycia, przestawienia i zmiany szerokości, dwie gęstości, zaznaczanie z akcjami zbiorczymi, menu przy każdym wierszu, miniatury i plakietki, strony z wyborem ich rozmiaru, eksport widoku do CSV i widok zapisany w adresie. Przełącz źródło na serwer, aby zobaczyć stronicowanie i szkielet podczas wczytywania kolejnej strony, a wybierz wszystkie wiersze, aby renderować tylko te widoczne.

UżycieLink do sekcji Użycie

tsx
import { DataTable } from '@skribly/ui/data'
tsx
const url = useTableUrlState({ prefix: 'posts.' })
<DataTable aria-label="Posts" columns={columns} items={posts} rowKey={(p) => p.id}
  labels={labels} {...url} pageSizes={[25, 50, 100]} resizable
  selectionMode="multiple" bulkActions={(rows) => <Button size="sm">Publish</Button>}
  rowActions={(post) => [{ id: 'open', label: 'Open', onAction: () => open(post) }]}
  isLoading={isLoading} loadingLabel="Loading posts" error={error} emptyState={empty} />
// Server data: manual total={page.total} items={page.rows}, and fetch with url.state.

Każda etykieta jest propem, więc aplikacja przekazuje własne słowa we własnym języku. Zobacz zasadę brak wbudowanego tekstu.

DostępnośćLink do sekcji Dostępność

  • Jeden przystanek Tab wchodzi do siatki; klawisze strzałek przechodzą między komórkami, Home i End wzdłuż wiersza, Spacja zaznacza wiersz, a wpisywanie przeskakuje do wiersza.
  • Nagłówek sortuje klawiszem Enter albo kliknięciem i tylko główny klucz sortowania ma aria-sort; kolejne klucze pokazują swoją pozycję i mówią ją słowami.
  • Krawędzie kolumn są separatorami, których szerokość zmieniają klawisze strzałek.
  • Pola i menu paska narzędzi mają nazwy, każdy chip filtra ma przycisk usuwania, a liczba pasujących wierszy jest odczytywana po wyszukiwaniu.
  • Kolumna nagłówków wierszy i nagłówek zostają na widoku podczas przewijania.
  • Ładowanie jest statusem, błąd komunikatem z przyciskiem ponowienia, a każdy stan jest wypowiedziany słowami.

Ten przykład przechodzi przez axe we wszystkich trzech motywach przy każdym uruchomieniu testów. Zobacz, co sprawdzają testy.
