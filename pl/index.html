Trzy warstwy, jedno źródłoLink do sekcji Trzy warstwy, jedno źródło

Tokeny są źródłem: kolory, typografia, odstępy, zaokrąglenia i ruch, zapisane raz jako pliki tokenów W3C i zbudowane w zmienne CSS. Zmień token, a każda warstwa pójdzie za nim.

Klasy czystego CSS dają każdej stronie te same przyciski, pola, karty i komunikaty, bez kroku budowania i bez frameworka.

Komponenty React dodają zachowanie. React Aria zapewnia obsługę klawiatury, zarządzanie fokusem i semantykę dla czytników ekranu, a tokeny zapewniają wygląd.
