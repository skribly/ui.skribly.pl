Motyw

Skribly UI

Tokeny, CSS i komponenty React pod każdym ekranem Skribly

24 grup komponentów i 256 komponentów na React Aria, w motywie dziennym, nocnym i wysokiego kontrastu z jednego zestawu tokenów. Żaden komponent nie ma wbudowanych słów: każda etykieta to prop, więc każda aplikacja pisze własne.

Pierwsze krokiPrzeglądaj komponenty

Podstawy

  • Tokeny projektoweKażdy kolor, rozmiar, zaokrąglenie, cień i czas trwania w Skribly UI, ze zmienną CSS i wartością w każdym motywie.
  • Czysty CSSKlasy .sk-* Skribly UI dla stron bez Reacta i bez Tailwinda, pokazane na żywo razem ze znacznikami do skopiowania.
  • DostępnośćJak Skribly UI jest budowany z celem WCAG 2.2 AA: co robi każdy komponent, co sprawdzają testy i za co nadal odpowiada aplikacja.

Czysty CSS na dowolnej stronie@import "@skribly/ui/plain.css";

A. Strona zeszytu

Tekst stoi obok linii w kolorze produktu, jak na stronie z marginesem. Spokojny i redakcyjny: niosą go krój pisma i spis stron.

Nagłówek i stopka pochodzą z ui.skribly.pl. Porównujemy tylko hero; strony zachowują własne menu.

Ten sam hero na skribly.pl, docs.skribly.pl, ui.skribly.pl
