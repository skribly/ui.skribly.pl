Design tokens

104 tokens: 45 shared by every theme and 59 colours with a value in each of the three themes. The tables on this page are generated from src/tokens/values.ts, so they always show what ships.

Where tokens come fromLink to the section Where tokens come from

The source is W3C design token files in tokens/. Style Dictionary builds them into tokens.css, the CSS variables every layer reads, and src/tokens/values.ts, a typed object for code that needs a value, such as a chart. npm test fails when the built files are stale.

Change a tokenbash
# edit tokens/*.tokens.json, then
npm run tokens
npm test
Read a value in codetsx
import { tokens } from '@skribly/ui/tokens'

tokens.dark.accent // '#f5b653'
tokens.foundation['radius-lg'] // '0.625rem'

ColourLink to the section Colour

Each column below is drawn in its own theme. Use the semantic name, never the value: bg-surface is white in light, near black in dark and pure black in high contrast. accent-text is the accent for text, because accent fails 4.5:1 as text on some surfaces.
