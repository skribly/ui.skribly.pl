Three layers, one sourceLink to the section Three layers, one source

The tokens are the source: colours, type, space, radius and motion, written once as W3C token files and built into CSS variables. Change a token and every layer follows.

Plain CSS classes give any page the same buttons, fields, cards and messages with no build step and no framework.

React components add behaviour. React Aria brings keyboard support, focus management and screen reader semantics; the tokens bring the look.
