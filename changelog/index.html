Changelog

What changed in each version. Versions follow semantic versioning, and apps pin a range with #semver in the git address.

Version 0.1.0Link to the section Version 0.1.0

November 2026In progress

The first version: tokens, plain CSS and the component groups every Skribly tool needs.

  • AddedDesign tokens in light, dark and high contrast, built from W3C token files into CSS variables and a typed object, with contrast tests for every text and control pair.
  • AddedPlain CSS classes for pages with no React: button, link, field, card, badge and alert.
  • AddedBrand: logo, wordmark, app lockup, avatars, agent chip, host and tracker badges, favicon letter.
  • AddedActions: buttons, icon, link, toggle and copy buttons, button groups, keys, drag handles, nudge buttons and gated actions.
  • AddedFeedback: alerts, banners, flash messages and toasts with polite and assertive announcements, badges, severity, status dots, spinners, skeletons, empty states, meters and progress bars.
  • AddedForms: fields, choices, pickers, settings rows, an error summary and form actions with a status line.
  • AddedNavigation, overlays, data, content, conversation, search, shell, surfaces, onboarding, pages, media and theme groups.
  • AddedTheme and reader settings: ThemeProvider, ThemeScript, ThemeToggle, AccessibilityProvider, SkipLink and live announcements.
  • ChangedThemeToggle shows its words always, never, or by its own width.
  • ChangedCollections memoize their state, so large tables and lists re-render less.
  • DocsThis site: every demo in three themes, usage, accessibility notes, tokens, patterns for messages, forms and layout, and an accessibility guide.
