Themes and density

Light, dark and high contrast are three sets of values for the same token names. A component never asks which theme is on; it reads the tokens and is right in all three.

Light is warm paper with an amber accent. Dark keeps the warmth with a lighter amber. High contrast is black with white lines and a yellow accent, for low vision and bright sunlight; text reaches 7:1 and control borders 4.5:1.

How the theme is chosenLink to the section How the theme is chosen

Set data-theme to light, dark or contrast on the root element. With no attribute, the operating system decides: prefers-contrast: more gives high contrast, then prefers-color-scheme: dark gives dark. The attribute also works on any element, which themes only that part of the page, as the previews on this site do.

Theme a whole page or one panelhtml
<html data-theme="dark">
  …
  <aside data-theme="contrast">Only this panel is high contrast</aside>
</html>

In React

ThemeProvider keeps the reader’s choice in local storage and sets the attribute. ThemeScript applies a stored choice before the first paint. ThemeToggle is the control, as a segmented group or a menu.

tsx
<ThemeProvider>
  <ThemeToggle
    label={t('theme')}
    variant="menu"
    options={{ light: t('light'), dark: t('dark'), contrast: t('contrast'), system: t('system') }}
  />
</ThemeProvider>

With Tailwind

Components never need dark:. App code that does gets a variant that follows the attribute, for dark and high contrast alike, so an app that uses it sets the attribute explicitly.

DensityLink to the section Density

data-density="compact" gives the smaller controls of the desktop apps. It changes the control heights only, so text stays readable, and the compact sizes still clear the 24px target size. The density switch at the top of this site sets it on the whole page.

Reader settingsLink to the section Reader settings

Two classes on the root carry the reader settings of the apps. a11y-reduce-motion stops motion like the system setting does, and a11y-strong-focus draws a 3px focus ring. AccessibilityProvider and AccessibilitySettings in the theme group manage them, with text size and underlined links.
