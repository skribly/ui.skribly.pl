DataTable for an admin view

The full grid of an admin panel on 2,000 posts: search, faceted filters with chips, sort by several columns (Shift with a click adds the next key), columns to hide, reorder and resize, two densities, selection with bulk actions, a menu on every row, thumbnails and badges, pages with a page size, CSV export of the view, and the view kept in the address. Switch the source to a server to see paging and a skeleton while the next page loads, and choose All rows to render only the rows in view.

UsageLink to the section Usage

tsx
import { DataTable } from '@skribly/ui/data'
tsx
const url = useTableUrlState({ prefix: 'posts.' })
<DataTable aria-label="Posts" columns={columns} items={posts} rowKey={(p) => p.id}
  labels={labels} {...url} pageSizes={[25, 50, 100]} resizable
  selectionMode="multiple" bulkActions={(rows) => <Button size="sm">Publish</Button>}
  rowActions={(post) => [{ id: 'open', label: 'Open', onAction: () => open(post) }]}
  isLoading={isLoading} loadingLabel="Loading posts" error={error} emptyState={empty} />
// Server data: manual total={page.total} items={page.rows}, and fetch with url.state.

Every label is a prop, so the app passes its own words in its own language. See no built-in text.

AccessibilityLink to the section Accessibility

  • One tab stop enters the grid; arrow keys move between cells, Home and End along a row, Space selects a row, and typing jumps to a row.
  • A header sorts on Enter or a click and only the main sort key carries aria-sort; further keys show their position and say it in words.
  • Column edges are separators the arrow keys resize.
  • The toolbar fields and menus are named, the filter chips each have a remove button, and the count of matching rows is read politely after a search.
  • The row header column and the header stay in view while the box scrolls.
  • Loading is a status, an error an alert with its retry button, and every state is said in words.

This demo runs through axe in all three themes on every test run. See what the tests check.
