Foundations

Plain CSS

106 classes for pages with no React and no Tailwind. They match the React components, read only the --sk-* variables, and sit in the components cascade layer so a page’s own CSS wins.

Set upLink to the section Set up

With a bundlercss
@import "@skribly/ui/plain.css";
Or straight from the HTMLhtml
<link rel="stylesheet" href="/node_modules/@skribly/ui/plain.css" />
<html data-theme="light">

Plain classes give the look and not the behaviour. Use real elements, such as button, a and label, and write the ARIA yourself where a component would have added it: link hints with aria-describedby, mark errors with aria-invalid, and put a tone word such as “Error:” in every alert, so colour never carries the meaning alone.
