Icons

One icon set for every Skribly app, free to use: the recommended names that say what an icon means, such as nav.settings or status.warning, and the complete Lucide set as a fallback. A 24 px grid, a 1.75 px stroke, round caps and joins, and three tones.

Icons by colourLink to the section Icons by colour

The same icons in the three tones, side by side. Each tone reads from the theme, so the panels follow the light, dark and high contrast themes. Pick a tone to see all the icons in it.

Mono

The text colour. The default, for every icon beside a word, in menus, buttons and tables.

Brand

The accent. For the current item of a menu or a product mark.

Duo

The accent stroke on the soft accent fill. For the few icons that should stand out.

Three tonesLink to the section Three tones

Mono follows the text colour around it and fits everywhere. Brand draws the stroke in the accent, for the current item of a menu or a product mark. Duo puts the accent stroke on the soft accent fill, for the few icons that should stand out, such as the products in the app switcher.

The accent keeps 3:1 against every surface in the light, dark and high contrast themes, and in the dark sidebar, which gives icons its own accent; test/icons.test.ts checks every pair. In forced colours the fill drops out and the stroke follows the system text colour.

An icon with no label is decoration and hidden from assistive technology: put a word beside it, or name the button it sits in. Give it a label only when it stands alone and carries meaning.

The complete Lucide setLink to the section The complete Lucide set

Every icon of Lucide is here, free to use, under the names lucide.arrow-down and so on. They are the fallback: when the registry has a name for what you mean, such as nav.settings, use that one, so a glyph can be redrawn for every app at once.

The Lucide icons are plain glyph data in their own entry, @skribly/ui/icons/lucide, with one named export per icon. Icon and the registry never import that data, and a bundler keeps only the icons you import. Lucide ships no categories, so the ones here are grouped by Skribly from the icon names. Brand logos are not part of the kit.

One Lucide icon in Reacttsx
import { GlyphIcon } from '@skribly/ui/icons'
import { lucideArrowDown, lucideTelescope } from '@skribly/ui/icons/lucide'

<GlyphIcon glyph={lucideArrowDown} />
<GlyphIcon glyph={lucideTelescope} tone="duo" size="sm" label="Telescope" />
The Lucide sprite, only for pages that ask for ithtml
<svg class="sk-icon sk-icon--duo" aria-hidden="true">
  <use href="/vendor/skribly-ui/icons-lucide.svg#lucide.telescope"></use>
</svg>

  <use href="/vendor/skribly-ui/icons.svg#status.ok"></use>
</svg>

The sprite icons.svg holds one symbol per name. Serve it from the package next to your pages and colour it with icons.css, which plain.css already imports.
